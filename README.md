# Bryan Villalobos — Premium Frontend

## Levantar local
```bash
npm install
npm run dev
```
Abrir http://localhost:3000

## Contenido editable
- `data/content.ts`: servicios, agenda y enlaces oficiales.
- `public/images/`: fotografías principales.
- `components/Sections.tsx`: música, videos, historia y contacto.

## Antes de producción
Confirmar con el artista: modalidades reales, biografía oficial, agenda, correo/WhatsApp/Instagram de booking y videos destacados. El correo mostrado actualmente es únicamente placeholder de maqueta.
